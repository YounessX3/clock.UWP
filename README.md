# clock.UWP
A UWP app that contains a stopwatch with a timer working perfectly in a simple clean UI

Instructions: how to install? first you need to get the latest release of the app, scroll down to assets and download both the clock.UWP_x_x86_x64_arm.msixbundle (the app package) and the certificate clock.UWP_1.0.3.0_x86_x64_arm.cer, then open the certificate, Install Certificate>Local Machine>Next > "yes" a security pop up> Place all certificate in the following store > Browse > Trusted Root Certification Authorities > Ok > Next > Finish. after that you open the clock.UWP_x_x86_x64_arm.msixbundle, click Install and you're good to go
